# wepick-threads-media

Public images for [@travel.hack.tw](https://www.threads.com/@travel.hack.tw) Threads posts (WePick).

- Uploaded automatically by the posting tool to `images/YYYY-MM-DD/<code>-<n>.png`.
- The Threads API fetches each image at publish time, so files older than 30 days are deleted.
- Images are fare-comparison screenshots only. No personal data or credentials.
